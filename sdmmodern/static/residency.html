6. Polls

Rankings for the dates picked above. Each member is rated from wins, in-the-money rate, finish quality, races run and recent form (the Top 10 also counts stakes and graded results). Small samples are pulled toward the average. Arrows compare with the same number of days just before.

7. Put a board on a website

Makes a snapshot of one board as a block of HTML with its own styling and no scripts. Paste it into a Divi 5 Code module, a WordPress Custom HTML block, or any page that accepts HTML. It shows the numbers as of the moment you make it. Make a new one after each update.

8. Public boards

A public board is a page that anyone can open or frame on their own website. It always shows the newest finished week and updates by itself as new races load (it can be up to 5 minutes behind). Only the board is public: no roster file, no stables list, no downloads. Only the site admin key can switch this on.
